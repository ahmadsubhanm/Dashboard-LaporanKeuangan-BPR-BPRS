# 🏦 BPR Financial Ratio Dashboard & Working Paper
*Dashboard Analisis dan Kertas Kerja Rasio Kesehatan Bank Perkreditan Rakyat (BPR / BPRS)*

Aplikasi web interaktif berbasis *Single-File HTML/JavaScript* yang dirancang khusus untuk menghitung, menganalisis, dan memonitor tingkat kesehatan bank secara otomatis. Proyek ini menggunakan studi kasus dan data finansial riil dari **PT BPR Alinma**.

---

## 🌟 Fitur Utama Sistem
* **Dashboard Rasio Otomatis**: Visualisasi kartu indikator dan tabel komprehensif untuk berbagai rasio penting perbankan.
* **Kalkulasi Standar Regulator (OJK/BI)**: 
  * **BOPO** (Biaya Operasional dibanding Pendapatan Operasional)
  * **LDR** (Loan to Deposit Ratio)
  * **Cash Ratio** (Rasio Likuiditas)
  * **ROA & ROE** (Rentabilitas)
  * **CAR / KPMM** (Kewajiban Penyediaan Modal Minimum & ATMR)
  * **NIM** (Net Interest Margin)
  * **MIAPB & PPAP**
* **Transparansi Rumus**: Setiap baris rasio dilengkapi dengan penjabaran rumus matematika beserta angka riil yang disubstitusikan.
* **Simulasi *What-If* (Uji Input Data)**: Menu khusus untuk melakukan simulasi perubahan angka keuangan tanpa mengubah data utama.
* **Dual Metode Penghitungan**: Mendukung metode kalkulasi sesuai laporan Excel standar maupun metode terkoreksi (*annualized*).

---

## 📂 Struktur Proyek
* **`index.html`** : Berkas utama aplikasi (berisi struktur HTML, desain CSS responsif, dan seluruh logika perhitungan finansial berbasis JavaScript).

---

## 🚀 Cara Menikmati / Menjalankan Aplikasi
Karena berbasis *client-side* murni, aplikasi ini tidak memerlukan instalasi *database* server (seperti MySQL) atau bahasa *backend* (seperti PHP).

1. **Secara Online (GitHub Pages)**:
   Aplikasi ini telah di-*deploy* dan dapat diakses langsung secara publik melalui link GitHub Pages repository ini.
2. **Secara Lokal**:
   * Unduh (Download ZIP) atau *clone* repository ini.
   * Cukup klik dua kali pada file **`index.html`** untuk membukanya langsung melalui browser web apa pun (Chrome, Edge, Firefox).
